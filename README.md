# Portfolio Risk Lab

Explore sample price history, normalized prices, weighted portfolio growth, annualized volatility, drawdowns, a simple zero-risk-free-rate Sharpe ratio, and correlations. Educational only; not investment advice.

## Run

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Definitions and limits are in [METRICS.md](docs/METRICS.md).
