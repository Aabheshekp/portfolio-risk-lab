# Metric definitions

- Daily return: close-to-close percentage change.
- Annualized arithmetic return: mean daily portfolio return multiplied by 252.
- Annualized volatility: sample standard deviation multiplied by square root of 252.
- Sharpe ratio: annualized arithmetic return divided by annualized volatility, assuming zero risk-free rate.
- Maximum drawdown: worst decline from a prior cumulative wealth peak.

These are simplified historical statistics and omit fees, taxes, cash flows, and benchmark selection.
